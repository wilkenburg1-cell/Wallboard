# Wallboard

Persönliches Info-Wallboard: Uhr, Termine, Verbindungen, Wetter mit Regenradar, Monatskalender und Nachrichten.

Öffnen: https://wilkenburg1-cell.github.io/Wallboard/

Alle persönlichen Einstellungen (Adressen, Kalender) werden nur im Browser des jeweiligen Geräts gespeichert, nicht in diesem Projekt.
